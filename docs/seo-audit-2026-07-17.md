## 1. Rendering Strategy — Severity: TINGGI

### Ringkasan per Halaman

| Halaman | Strategi | Detail Fetching |
|---|---|---|
| `/` (Home) | Hybrid — Server Component shell, konten via client fetch | `src/app/page.tsx:28` → `src/components/home/home-client.tsx:12` (`useGetDataHome()` → `/api/guest`) |
| `/about` | **Full Client Component ❌** | `src/app/(guest)/about/page.tsx:1` (`"use client"`) → `useGetDataAbout()` → `/api/guest/about` |
| `/blogs` | Hybrid — Server Component shell, data via client fetch | `src/app/(guest)/blogs/page.tsx:22` → `blogs-client.tsx:54` (`useGetGuestBlogs()`) |
| `/writings` | Hybrid — Server Component shell, data via client fetch | `src/app/(guest)/writings/page.tsx:22` → `writings-client.tsx` (`useGetGuestWritings()`) |
| `/projects` | Hybrid — Server Component shell, data via client fetch | `src/app/(guest)/projects/page.tsx:32` → `projects-client.tsx` (`useGetGuestProjects()`) |
| `/blogs/[slug]` | ✅ **Server Component async — Prisma langsung** | `src/app/(guest)/blogs/[slug]/page.tsx:44` |
| `/writings/[slug]` | ✅ **Server Component async — Prisma langsung** | `src/app/(guest)/writings/[slug]/page.tsx:44` |
| `/projects/[slug]` | ✅ **Server Component async — Prisma langsung** | `src/app/(guest)/projects/[slug]/page.tsx:39` |

### Masalah

1. **5 halaman bergantung client-side fetching (Home, About, Blogs list, Writings list, Projects list)**
   - Googlebot bisa mengeksekusi JavaScript, tapi React Query fetch berjalan **setelah** render awal → konten utama (judul, deskripsi, daftar item) tidak langsung ada di HTML response.
   - Untuk portfolio pribadi, **Home** dan **About** adalah halaman paling kritis untuk indeks, namun keduanya menggunakan client fetch.
   - Dampak: Konten mungkin tidak terindeks atau terindeks sebagian oleh search engine.

2. **Tidak ada `generateStaticParams`** — Semua halaman `[slug]` di-render per-request (dynamic SSR). Tidak ada pre-render statis.

3. **Tidak ada `revalidate` atau `fetch` cache config** — Nol strategi ISR/caching. Setiap request memicu query database dan render ulang.

### Rekomendasi

| Priority | Tindakan | File Target |
|---|---|---|
| **P1** | Konversi `/about` jadi async Server Component — pindahkan fetch dari `useGetDataAbout()` ke `prisma` langsung, hapus `"use client"` | `src/app/(guest)/about/page.tsx` |
| **P1** | Konversi Home page — jadikan page async, fetch data via Prisma, passing props ke `HomeClient` (ikuti pola `blogs/[slug]`) | `src/app/page.tsx`, `src/components/home/home-client.tsx` |
| **P2** | Konversi Blogs/Writings/Projects list — fetch data via Prisma di Server Component, passing props ke client component | `src/app/(guest)/{blogs,writings,projects}/page.tsx` + masing-masing `*-client.tsx` |
| **P2** | Tambah `generateStaticParams` + `revalidate` di `blogs/[slug]`, `writings/[slug]`, `projects/[slug]` untuk pre-render statis + ISR | `src/app/(guest)/{blogs,writings,projects}/[slug]/page.tsx` |
